# Code Game React - Loja de Games

**Code Game React** é uma página frontend de uma loja de games criada para praticar React e CSS. A página exibe uma galeria de cards de jogos, utilizando componentes do React e CSS para estilização. Esta aplicação foi implementada como um exercício prático de desenvolvimento front-end.

Você pode acessar a página em [Code Game React - Deploy](https://projeto-code-game-react.vercel.app/).

## Funcionalidades

- **Exibição de Cards de Jogos**: Cada card exibe o nome do jogo, uma imagem e informações relevantes.
- **Navegação Simplificada**: Utilização de React Router para navegação entre as páginas.
- **Formulários**: Gerenciamento de formulários simples com React Hook Form.
- **Estilização com Bootstrap**: Utilização do Bootstrap e React-Bootstrap para garantir uma interface responsiva e estilizada.

## Tecnologias e Dependências

Este projeto foi construído utilizando as seguintes tecnologias e bibliotecas:

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **React-DOM**: Pacote para manipulação do DOM com React.
- **React-Bootstrap**: Componentes de Bootstrap para React.
- **Bootstrap**: Framework CSS para design responsivo e estilização.
- **React-Router-Dom**: Biblioteca para gerenciamento de rotas no React.
- **React-Hook-Form**: Biblioteca para gerenciamento de formulários em React.
